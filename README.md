# Neuro Explorer

Web educativa para aprender neurociencia de forma visual.

- **Atlas 3D**: modelo interactivo del cerebro (lóbulos, áreas funcionales, estructuras profundas, tronco encefálico y cerebelo) con fichas de función, lesiones y datos clave.
- **Procesos**: lecciones animadas paso a paso (potencial de acción, sinapsis, reflejo rotuliano, vía visual, memoria, recompensa y estrés) con preguntas de repaso.

Sitio estático en un solo `index.html` (Three.js desde CDN). Contenido con fines educativos; el modelo 3D es esquemático.

Diseño: Mapa Bianchi.
